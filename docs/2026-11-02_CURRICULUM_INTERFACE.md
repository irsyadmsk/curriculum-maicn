# Tampilan dan panduan guru — 2 November 2026

Permintaan pemilik: ubah total warna dan tampilan agar jelas, langsung ke kebutuhan pengguna, nyaman di HP, serta memberi bantuan pengisian guru.

Perubahan:

- Palet teal, putih, dan amber; sidebar teal gelap, navigasi aktif amber, panel/form/status mengikuti token yang sama termasuk ruang admin. Huruf yang sudah tersedia dipertahankan tanpa paket atau font baru.
- Beranda: akses Klinik, Switch, Panduan; informasi hari ini, klinik, pengumuman, piket, dan Senin JP 1 tetap berasal dari sumber yang sama.
- Tombol Panduan pada posisi konsisten di header. Empat topik: Klinik, Switch, Kokurikuler, Status. Dapat ditutup kapan saja, tanpa panggilan AI, email, atau layanan eksternal.
- Klinik baru mulai dari Guru, dengan pilihan Murid tetap tersedia. Identitas pengampu dan mapel berada sebelum roster peserta. Pilihan peserta tetap terlihat; filter dan daftar dapat digulir.
- Bantuan tiga tahap dapat melompat ke isian, memberi petunjuk berikutnya dan ringkasan nama, sesi, serta jumlah peserta. Bukti/foto/email tetap opsional; draf dan penerimaan server dibedakan.
- Ukuran kontrol sentuh 44–50 px, tata letak satu kolom pada HP, menu header membungkus tanpa memotong tombol, serta dukungan reduced motion. Cetak tidak memuat tombol/panduan.
- Versi aset CSS/JS diperbarui pada 24 halaman. Tidak mengubah data sekolah, otorisasi, skema database, ataupun keputusan admin.

Skill: UI/UX Pro Max, minimalism/Swiss untuk dashboard dan rekomendasi palet LMS teal/amber; tombol teal digelapkan untuk keterbacaan teks. Pemeriksaan sintaks modul dan build 120 aset berhasil.
