# Curriculum: rilis akses dan kurikulum

Kandidat rilis 26 Oktober 2026, atas instruksi pemilik untuk commit, merge, dan deploy.

Antarmuka memakai murid, kokurikuler, delapan dimensi profil lulusan dan Panca Cinta. Informasi murid tidak memerlukan akun; permintaan Klinik boleh dari tamu atau akun umum. Data murid, nilai, presensi, pengamatan dan laporan memerlukan akun guru terverifikasi. Keputusan Klinik dan Senin JP 1 tetap khusus admin/kurikulum. Status akun serta keharusan mengganti sandi diperiksa sebelum memberi akses.

Build hanya menerbitkan aset terkurasi lewat Worker dengan run_worker_first; jangan mengunggah repo sebagai situs statis. Berkas roster bernama assets/student-roster-data.js merupakan input privat yang dihasilkan lokal oleh scripts/import-student-roster.py. Berkas tersebut dan private-inputs/ tidak boleh di-commit ke repo publik. Build menolak roster yang hilang. Catatan booking lama berada dalam input privat opsional private-inputs/clinic-legacy.json; label historis bukan persetujuan baru. Sumber akademik yang di-commit hanya berisi informasi publik.

Native schema, akun pengelola, secrets dan pemasangan layanan diverifikasi pada receipt privat operator. Paket SQL kanonis berada di repo Irsyads; ekspor core/client/access harus identik dengan packages/curriculum-clinic. Tidak ada pengiriman email/WhatsApp/push dalam rilis ini. Presensi, nilai dan pengamatan perangkat tetap diberi label penyimpanan perangkat; tidak mengklaim sinkron server atau tanda tangan digital. Nilai kosong berbeda dari nol.

Bukti sebelum rilis: 58 tes repo lokal, 3 tes SQL PGlite dan 3 tes React Klinik/Senin lulus. Aktivasi online dan identitas deployment dicatat setelah publikasi terverifikasi.
